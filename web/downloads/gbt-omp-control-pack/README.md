## 🚀 快速开始

### Windows
```
下载 gbt-omp-control-pack.zip → 解压 → 双击 install.bat
```

### Mac / Linux
```bash
curl -O https://gbtxiaotudou.com/downloads/gbt-omp-control-pack.zip
unzip gbt-omp-control-pack.zip && cd gbt-omp-control-pack
bash install.sh
```

## 🔧 启动方式

```bash
cd ~/GBTxiaotudouV5
omp                 # 交互模式
omp --mode rpc      # API模式(供外部程序调用)
omp --collab        # 协作模式(生成分享链接)
```
