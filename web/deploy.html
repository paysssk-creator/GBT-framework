部署指南

一键部署 GBT小土豆

GBT 将全自动在你的服务器或本地电脑上部署 GBTxiaotudouV5 智能大脑。全平台支持，~30s 启动。

PowerShell
# 以管理员身份运行 PowerShell，粘贴并回车 PS> irm https://raw.githubusercontent.com/paysssk-creator/GBTxiaotudouV5/master/deploy.ps1 | iex
Bash
# 打开终端，粘贴并回车执行 $ curl -fsSL https://raw.githubusercontent.com/paysssk-creator/GBTxiaotudouV5/master/deploy.sh | bash
Docker
# 拉取镜像并启动容器，端口 3000，持久化数据 $ docker run -d --name gbt-pod -p 3000:3000 -v gbt-data:/data paysssk/gbt-pod:latest

↑ 复制上方命令，粘贴到终端中运行即可

常见问题

遇到困难？

以下是部署过程中最常见的问题与解决方案

请确保使用 PowerShell 5.1 或更高版本。可在 PowerShell 中运行 $PSVersionTable.PSVersion 查看当前版本。Windows 7 用户请手动安装 WMF 5.1。

Ubuntu/Debian: sudo apt install curl — macOS 已预装 curl。也可使用 wget -qO- URL | bash 替代。

尝试使用国内镜像源：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple。如仍失败，请检查 Python 版本是否 ≥ 3.10。

运行 omp --port 3001 指定其他端口，或在 Docker 中使用 -p 3001:3000 映射到不同宿主机端口。

配置 Docker 镜像加速器：在 Docker Desktop → Settings → Docker Engine 中添加 "registry-mirrors": ["https://mirror.ccs.tencentyun.com"]。
