❓ 常见问题

OMP 是什么？
OMP (Oh My Pi) 是一个 AI 驱动的命令行外壳，类似 Claude Code / Cursor 终端。它让 AI 可以直接操控你的电脑——读写文件、运行命令、操控浏览器。OMP 原生控制包将 OMP + GBT大脑 打包成一键安装。
需要什么系统要求？
Windows 10/11、macOS 12+、Ubuntu 20.04+。需要 Python 3.10+（安装包会自动检测并安装）。推荐 8GB+ 内存以获得流畅的 AI 视觉分析体验。
需要付费吗？
GBT小土豆本身完全免费开源。AI 功能需要 DeepSeek API Key（新用户免费 500 万 tokens），OMP Shell 基础版免费。
安装后如何启动？
安装完成后，打开终端进入 GBTxiaotudouV5 目录，输入 omp 即可启动 AI 对话。输入 omp --mode rpc 可启动 API 模式供外部程序调用。
