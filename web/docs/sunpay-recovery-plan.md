## 四、行动清单（按优先级）

### 第1步：Apple App Store 投诉退款 ⭐⭐⭐
```
1. 打开 reportaproblem.apple.com
2. 登录你的Apple ID
3. 找到 SunPay Global → "报告问题"
4. 选择: "请求退款" + "应用未按预期工作"或"未收到服务"
5. 附上: 你的付款凭证截图
6. 如果App内有内购/充值，一并申请
```

### 第2步：银行/支付平台争议 ⭐⭐⭐
```
信用卡/借记卡:
→ 联系发卡行 → 申请chargeback
→ 理由: "商品/服务未提供" 或 "未经授权交易"
→ 提供: 交易日期、金额、商户名称(SunPay/BITLEADER)
→ 时限: 通常60-120天

支付宝/微信支付:
→ 打开交易记录 → 对此订单有疑问 → 投诉
→ 附上: App截图+聊天记录

加密货币:
→ 请提供交易哈希(TXID)，我帮你追踪
→ 可能路径: 联系交易所冻结收款地址
```

## ⛔ 为什么不能攻击

1. **攻击违法的服务器让你从受害者变被告**
2. **钱在数据库/钱包里，不在网页上 — DDoS/入侵拿不回钱**
3. **AWS+Cloudflare防护 — 你的IP先被封**
4. **金融服务器受《计算机欺诈和滥用法》保护 — 最高20年**

> 真正的追回路径是法律+金融渠道，不是黑客手段。
