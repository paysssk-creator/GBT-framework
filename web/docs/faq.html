常见问题

部署失败了怎么办？

常见原因：① 仓库不是公开的 → 设为 Public；② 缺少依赖声明文件（requirements.txt / package.json）→ 补充；③ 端口未正确暴露 → 确认项目监听 0.0.0.0 而非 127.0.0.1。查看部署日志：登录面板 → 项目 → 构建日志。

支持哪些项目类型？

Python（Flask/FastAPI/Django/Streamlit/Gradio）、Node.js（Express/Next.js）、Go、静态网站、ComfyUI、Stable Diffusion WebUI、Ollama 等。只要是能通过 HTTP 访问的服务都支持。

项目租不出去怎么办？

① 检查定价是否合理（参考同类项目）；② 完善项目描述和截图；③ 在社交媒体分享你的项目链接；④ 加入 GBT 开发者社区获取推广支持。

收益如何提现到国内银行卡？

推荐路径：GBT 钱包 → TRC20 USDT → 币安/OKX → C2C 卖出 → 银行卡。全程手续费极低。或直接使用 Stripe 提现到支持的国际银行卡。

代码安全吗？会被别人看到吗？

你的源代码经过 AES-256 加密存储，运行在隔离的 Docker 沙盒中。租户只能通过 HTTP 接口使用你的服务，无法访问源代码和内部文件。

可以自定义域名吗？

可以。在项目设置中添加你的域名，配置 CNAME 记录指向 tunnel.gbtxiaotudou.com 即可。

收益什么时候到账？

每周一自动结算上周收益到你的 GBT 钱包余额。可以随时提现（TRC20 USDT 即时到账，Stripe 1-3个工作日）。
