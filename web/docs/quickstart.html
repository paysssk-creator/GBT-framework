5分钟部署第一个项目

只需要一个 GitHub 链接，不需要写 Dockerfile，不需要配服务器。

前提条件

✅ 一个公开的 GitHub 仓库（Python / Node.js / Go / 静态站均可）
✅ GBT 开发者账号（免费注册）

部署步骤

1
粘贴仓库地址

在首页输入框或 开发者面板 粘贴 GitHub 链接

2
AI 自动分析

GBT 自动检测：语言（Python/Node/Go）→ 依赖文件（requirements.txt/package.json）→ 端口号 → 启动命令

3
等待构建（~30秒）

AI 生成 Dockerfile → 构建镜像 → 配置内网隧道 → 生成公网地址

4
上线！

获得 https://your-project.gbtxiaotudou.com 公网地址，自动上架项目市场

CLI 部署（进阶）

# 安装 CLI
pip install gbt-cli
# 一键部署
gbt deploy https://github.com/your/awesome-project
# 查看状态
gbt status
# 查看收益
gbt earnings

API 部署

curl -X POST https://api.gbtxiaotudou.com/deploy \
  -H "Authorization: Bearer $GBT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"repo_url":"https://github.com/user/project","name":"my-app"}'
💡 部署后项目自动进入"审核队列"，AI 自动评估质量并定价。通常 1-5 分钟完成。
