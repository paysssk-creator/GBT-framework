🔒 安全

加密方案、隔离机制、隐私保护与合规。

所有项目源码使用 AES-256-GCM 加密存储：
• 业界最强的对称加密标准（256 位密钥）
• GCM 模式提供认证加密（防篡改）
• 每个项目使用独立密钥
• 运行时解密到内存，使用后立即清除
• 密钥通过硬件安全模块（HSM）管理
每个项目实例运行在独立容器中：
• 无网络访问（除非项目明确需要 API 调用）
• 只读文件系统（不可修改容器内容）
• CPU 和内存硬限制（防止资源耗尽）
• 会话结束后容器立即销毁
• 无特权模式、无宿主机挂载
• 传输层：所有通信使用 TLS 1.3 加密
• 存储层：AES-256 加密 + 密钥分离管理
• 用户数据：最小化收集，详见 隐私政策
• 会话隔离：用户间数据完全隔离
• 日志：不含敏感信息，保留 30 天自动清除
